# d3ForceVAST2018MC3

For the 2018 MC3 VAST Challenge, I took data into Tableau for an initial analysis.
Afterwards, I wanted to look at the data in a network view, which is why I got d3 involved. I converted the separated suspicious data into a combined form as a csv. This data was smaller, but I wanted to make sure it was granular enough that I could double check the accuracy of it all.
I added a file with limited suspicious data, and one with some fake data to test the colors functionality.
